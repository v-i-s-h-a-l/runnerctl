# Agent-First Onboarding Docs Plan

## Objective

Reframe Runnerctl documentation so the recommended path is cloning the repository, opening it in an AI coding agent, and asking for runner lifecycle work in natural language. Raw CLI commands remain available as the canonical execution layer and fallback, but they are not the primary user-facing path.

## Work Items

1. Update README to lead with the AI-agent workflow.
2. Add a user guide with example natural-language requests and expected agent behavior.
3. Expand `AGENTS.md` into a practical routing contract for agents.
4. Update product docs and roadmap status to reflect agent-first onboarding.

## Completion Criteria

- A user can read the README and understand that they should open the repo in an agent first.
- An agent can read `AGENTS.md` and map common natural-language requests to current Runnerctl commands.
- CLI commands are documented as fallback/execution details, not as the recommended interaction model.
